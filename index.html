Das dynamische Beziehungs-Gedächtnis

Statt bloßem Text speichern wir die Kommunikation in einem Wissensgraphen (Graph-RAG). So versteht das System, dass "Klarheit" für Philipp etwas anderes bedeutet als für Lena.

1. Extraktion

Ein LLM isoliert Konzepte aus dem Chat.

2. Konsolidierung

Der Graph wird via Tool-Calling (ADD/UPDATE) aktualisiert.

3. Retrieval

Bei neuen Nachrichten wird die relationale Differenz berechnet.
